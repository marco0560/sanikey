# Esempi di Configurazione

Questa directory contiene esempi pubblicabili di configurazione.

- `accounts.toml` è il modello da copiare in `config/accounts.toml` e
  compilare con i percorsi locali;
- `search-dictionary.toml` è il dizionario opzionale di sinonimi e mesi,
  referenziato da `[global.search]` o `[person.search]` in `accounts.toml`.

Non inserire qui percorsi reali, nomi di persone, UUID reali o dati sanitari.
